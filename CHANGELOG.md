# Changelog

## 0.1.0

Initial package:

- Import and render trained 3DGS and 2DGS models.
- Built-in, URP Render Graph and HDRP integrations, with direct and composite rendering paths.
- Desktop and XR camera support, with optional URP splat depth output and SRP foveation support.
- Export, import and animate supported HexPlane 4DGS models with Native or ONNX deformation.
- Scene-authored benchmarks with repeatable inputs, timing results and separate desktop diagnostics.
